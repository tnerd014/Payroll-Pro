Payroll Pro — Instruction Manual Section 1: Executive Overview

01 Executive Overview & System Architecture

Payroll Pro is a specialized enterprise application built to handle the complex statutory, tax, and pension realities of operating in Nigeria. It eliminates spreadsheet errors, enforces compliance with federal and state regulations, and streamlines disbursement through Nigerian commercial banks.

🔒 Dual-Mode Multi-Tenancy

Operates fully offline on isolated local storage or connects seamlessly to private Supabase PostgreSQL instances for multi-branch team collaboration.

⚡ Zero-Latency Role Enforcement

Role promotions, demotions, and operator deactivations take effect across remote operator windows in sub-seconds via Supabase Realtime CDC.

🇳🇬 Complete Nigerian Compliance

Built-in models for PITA 2011, Finance Act 2020, Pension Reform Act 2014, and the upcoming 2026 Nigerian Tax Reform Bill progressive brackets.

🛡️ Non-Destructive Background Sync

Silent multi-layered polling and WebSocket updates refresh data in memory without table unmounting, layout shifting, or screen flickering.

System Architecture & Data Flow

Offline-First Resilience: All changes made by operators are immediately written to local memory and persistent storage, followed by optimistic background synchronization to Supabase Cloud. If network connectivity drops, operators can continue processing payroll without interruption; changes sync automatically upon reconnection.
Component Technology Operational Function
Desktop Shell Electron 44 (x64) Provides high-performance native Windows integration, tray support, local file system access, and native print-to-PDF generation.
User Interface React 18 & Tailwind CSS Reactive, dark-mode ready UI with zero third-party component bloat, tailored for high-volume tabular accounting operations.
Computation Engine Pure TypeScript Deterministic, audit-ready mathematical engine implementing Nigerian statutory emoluments, CRA formulas, and marginal tax bands.
Cloud Database Supabase (PostgreSQL 14+) Multi-tenant relational database with foreign key cascades, Row Level Security (RLS), and Realtime WebSocket replication.

02 Authentication & Multi-Company Workspaces

Payroll Pro isolates data by legal corporate entities. Operators sign into the system with their verified credentials and then select or unlock their target company workspace.

2.1 Cloud Staff Access Gate

Upon launching the application, the system presents the Cloud & Staff Access Gate:

  • Enter Operator Credentials: Enter your registered Work Email or Username and Password.
  • Automatic Session Retention: Check "Remember me on this workstation" to bypass subsequent login prompts on secure company computers.
  • First-Time Admin Setup: If connecting to a newly deployed database, the gate prompts you to register the Master Administrator with an initial security question and answer.
  • Connecting a Private Server: Click Connect Server in the top-right corner to input your organization's private Supabase URL and Anon Public Key.

2.2 Windows OS-Style Account Picker

Once authenticated, the system presents the interactive workspace gallery:

Multi-Entity Switching: Holding companies and accounting firms managing multiple subsidiaries can switch between workspaces in seconds. Each company maintains its own distinct logo, password, staff register, and locked historical snapshots.

Workspace PIN / Password If a workspace has password protection enabled, clicking the card prompts for the confidential PIN/password before granting entry.

2.3 Self-Service Password Recovery

If an operator forgets their login credentials, they can perform self-service recovery:

  • Click Forgot Password? on the login screen.
  • Enter the registered Work Email or Username.
  • The system verifies the account and presents the confidential Security Question registered during onboarding.
  • Provide the exact Security Answer to immediately unlock the account and set a fresh confidential password.

Payroll Pro — Instruction Manual Section 4: Monthly Payroll Processing

04 Monthly Payroll Computation & Finalization

The Payroll Processing module computes gross-to-net calculations in real-time, factoring in mid-month stint prorations, monthly bonuses, loan repayments, and statutory tax deductions.

4.1 Computation Workflow

  • Select Cycle: Click the target month (e.g., October) and year from the top period ribbon.
  • Review Prorations: Staff joining or leaving mid-month have their gross earnings automatically prorated by active calendar days.
  • Apply Active Loan Deductions: Scheduled staff loan and advance deductions are automatically integrated into each employee's deductions column.
  • Audit Ledger Figures: Inspect Gross Pay, CRA Relief, Taxable Income, PAYE Tax, Pension (8%), Employer Pension (10%), and Net Take-Home Pay.
  • Lock Period Snapshot: Finalize the run to archive the numbers permanently against accidental retrospective modification.
  • Generate Bank Schedule: Export the validated NUBAN schedule for corporate internet banking upload.

4.2 Stint & Proration Logic

When an employee has a recorded Start Date or Exit Date falling within the active processing month, Payroll Pro applies exact calendar proration:

// Calendar Day Tenure Proration Formula
Proration Factor = Active Days in Month / Total Calendar Days in Month
Prorated Gross = Base Gross Salary * Proration Factor

4.3 Period Snapshot Locking & Historical Archiving

To protect accounting integrity, completed payroll runs must be locked:

Snapshot Parameter Compliance & Operational Rule
Lock Confirmation Presents an executive summary: Total Gross, Total PAYE, Total Pension, and Net Disbursed.
Audit Attribution Records the authorizing operator's name, role, timestamp, and optional run notes.
Immutable Lock State Once locked, the period displays a golden padlock (🔒 Locked). Subsequent changes to employee base salaries in future months will not alter this finalized historical ledger.
Unlock Privilege Only Master Administrators can unlock a finalized run, and doing so generates an immediate priority entry in the system audit log.

Manage company lending programs, short-term salary advances, monthly payroll amortizations, and balance tracking without external spreadsheets.

5.1 Facility Types

Facility Type Standard Term Operational Purpose & Usage

5.2 Disbursing a Loan Facility

  • Navigate to Loans & Advances (Alt + 4).
  • Click + New Facility.
  • Select the Employee from the searchable dropdown.
  • Select the Facility Type and enter the Principal Amount (₦).
  • Enter the Monthly Deduction Amount (₦) (or loan duration in months).
  • Select the Repayment Start Period (e.g., 2026-may).
  • Click Create Facility. The monthly deduction automatically binds to payroll processing starting from the chosen cycle.

5.3 Auto-Deduction & Lifecycle Tracking

Automatic Completion: When a monthly payroll run is executed, active loan deductions are deducted from the employee's net pay. The facility's remaining balance decreases automatically. When the balance hits ₦0.00, the facility status flips to Completed and deductions automatically cease.

5.4 Facility Actions: Pause, Resume & Manual Payments

Clicking the minimalist 3-dot action menu (•••) on any facility provides:

  • Pause Facility: Temporarily halts payroll deductions during staff hardship or special leave.
  • Resume Facility: Restores monthly payroll amortizations.
  • Record Manual Payment: If an employee repays cash directly, record the transaction to reduce the balance and log the receipt in the loan's audit history.
  • Edit Facility: Adjust monthly deduction amounts, remaining balance, or facility terms.

Payroll Pro — Instruction Manual Section 7: Statutory Compliance

07 Statutory Compliance & Mathematical Models

Payroll Pro implements the exact statutory calculation rules of the Personal Income Tax Act (PITA 2011), the Pension Reform Act 2014 (PRA 2014), and the 2026 Nigerian Tax Reform Bill.

7.1 Emolument Allocations & BHT Base

Gross earnings are automatically allocated into statutory allowances:

  • Basic Salary: 40% of Gross (Pensionable & Taxable)
  • Housing Allowance: 30% of Gross (Pensionable & Taxable)
  • Transport Allowance: 20% of Gross (Pensionable & Taxable)
  • Other Allowances: 10% of Gross (Non-Pensionable & Taxable)

The sum forms the statutory BHT Emolument: BHT = Basic + Housing + Transport = 90% of Gross.

7.2 Statutory Pension (PRA 2014)

Employee Pension Deduction = BHT * 8% (7.2% of Gross — 100% Tax Deductible)
Employer Pension Contribution = BHT * 10% (9.0% of Gross — Company Expense)

7.3 Consolidated Relief Allowance (CRA)

Statutory Regime Annual CRA Formula Monthly Equivalent
PITA 2011 / Finance Act max(₦200,000, 1% Gross) + 20% Gross max(₦16,666.67, 1% Gross) + 20% Gross
2026 Tax Reform Bill ₦800,000 Base + 20% Gross ₦66,666.67 Base + 20% Gross

7.5 Worked Numerical Example (₦500,000 Monthly Gross)

1. Monthly Gross: ₦500,000.00 (Annual: ₦6,000,000.00)
2. BHT Emolument: ₦450,000.00 (Basic ₦200k + Housing ₦150k + Transport ₦100k)
3. Employee Pension (8%): ₦36,000.00 (Tax Deductible)
4. Employer Pension (10%): ₦45,000.00 (Company Liability)
5. Monthly CRA Relief: ₦116,666.67 (₦200k/12 + 20% of ₦500k)
6. Chargeable Taxable Income: ₦500,000 - ₦36,000 - ₦116,666.67 = ₦347,333.33
7. Monthly PAYE Tax (PITA): ₦66,026.67
8. Net Take-Home Pay: ₦500,000 - ₦36,000 - ₦66,026.67 = ₦397,973.33

Payroll Pro — Instruction Manual Section 9: Troubleshooting & Backups

09 Troubleshooting, Data Backup & Disaster Recovery

Procedures for system maintenance, encrypted local backups, and resolving common operational edge-cases.

9.1 Local Encrypted Backups

Under Settings -> Data Backup, administrators can generate an encrypted .json database dump containing all company entities, employees, loans, locked historical runs, and audit logs.

Recommended Backup Schedule: Export an encrypted local backup at the conclusion of every monthly payroll cycle immediately following period snapshot locking.

9.2 Disaster Recovery Procedure

  • Deploy a fresh Supabase database instance.
  • Execute schema.sql via the Supabase SQL Editor to initialize relational tables.
  • Launch Payroll Pro and enter the new Supabase URL and Anon Key at the login gate.
  • Navigate to Settings -> Restore from Backup and select your latest verified .json backup file.
  • The system validates and restores all companies, employees, and historical snapshots within seconds.

9.3 Frequently Asked Questions & Troubleshooting

Symptom / Question Root Cause & Resolution
Why does a staff member's take-home pay appear lower than expected? Check the employee's profile for: (1) Mid-month Start or Exit date activating calendar day proration; (2) Scheduled loan/salary advance deduction; or (3) A monthly override value set for that cycle.
Table flickering or reloading constantly? Resolved in version 1.0.2. Background synchronization and polling routines operate in silent mode, preserving table state and active row inputs without layout shifts.
Can I edit a staff member's salary after locking a period? Yes. Updating base gross salary will update all future unlocked periods. The locked period snapshot remains permanently preserved as finalized.
How do I change statutory pension rates? Administrators can navigate to Settings -> Variables to adjust Employee Pension (8%) and Employer Pension (10%) rates to match special collective bargaining agreements.
